# 📊 Mayur Stationery Sales Analysis

## 📌 Project Overview

This project is an **Applied Business Analytics** study of the Mayur Stationery Sales Dataset. The project uses Python-based data analysis techniques to understand sales performance, customer behavior, payment methods, discounts, forecasting, and business decision-making.

## 🎯 Objectives

* Analyze stationery sales data.
* Clean and preprocess the dataset.
* Perform Exploratory Data Analysis (EDA).
* Apply statistical and probability techniques.
* Analyze sales trends and forecast future sales.
* Perform optimization and decision analysis.
* Create visualizations and a business dashboard.
* Generate useful business insights and recommendations.

## 🗂️ Dataset

The dataset contains information such as:

* Date
* Transaction ID
* Product
* Category
* Store Location
* Payment Method
* Units Sold
* Unit Price
* Discount Applied
* Customer Age
* Net Price
